# GitHub setup checklist

## Create the repository

Create a new public GitHub repository named:

`Soccer-Predict-Lab`

Do **not** initialize it with another README if you are uploading this project.

## Upload from command line

Inside the project folder:

```bash
git init
git add .
git commit -m "Initial release: soccer prediction ML pipeline"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Soccer-Predict-Lab.git
git push -u origin main
```

## Recommended GitHub description

> ML-powered soccer match prediction lab for 1X2, Over/Under 2.5, BTTS and scoreline probabilities using CatBoost and rolling form features.
